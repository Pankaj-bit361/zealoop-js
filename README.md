# zealoop-js

AI customer support agent for SaaS teams — docs-grounded answers, customer data lookups, and real actions behind code-level guards.

**Official site:** [https://www.zealoop.com](https://www.zealoop.com)

## Install

```bash
npm install zealoop-js
```

## What it does

This lightweight client connects your Node.js scripts and AI agents to zealoop.

- Simple API wrapper — no config files needed
- Works with the zealoop MCP endpoint: `https://api.zealoop.com/mcp`
- Typed responses, zero dependencies
